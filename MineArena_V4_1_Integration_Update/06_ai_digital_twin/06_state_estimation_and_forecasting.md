# Runtime estimation and forecast integration
State key namespace + patient/subject + variant + session. Reconstruct observed state from accepted data, context and previous baseline; do not replace original observations with predictions. For each fixed 15s frame, estimator uses reliable observations and past eligible estimates, marks missing as unknown or explicitly estimated; state reconciliation with documented observation quality weighting and parameter bounds approved by AI. Do not learn shared weights online. Use immutable manifest/frame and context version, model/encoder/equation versions and deadline; queue independently from P0 safety. All accepted events feed timeline even urgent; baseline freeze remains clinical policy. Store checkpoint and lineage, model result status and timing; apply CAS only if matching current key/version, discard stale for current state but retain audit. On session reset no reuse of baseline/model state. Model timeout or missing artifact -> explicit failed/unavailable; insufficient coverage/OOD -> abstained. No mock values.

Forecast output: origin source time, target offsets (15s grid proposal), per-vital trajectory and units, observed/estimated origin distinction, uncertainty intervals if calibrated, horizon and validity, assumptions/limitations, model version, manifest/frame/context refs, execution latency. 5min primary, 15min secondary, 30min experimental. Unknown future activity/interventions cannot be known; record assumption. Prediction interval not certainty. Clinical decision consumes eligible verified forecasts only; experimental cannot independently change priority or lower mandatory floor. UI shows solid observed, distinct estimates, dashed predictions and interval bands, unavailable state when no output. Monitor queue age and inference timeout; defer model under load without stopping clinical timeline.
