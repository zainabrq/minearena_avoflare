Group counts and 15s timeline are frozen V4.1. Exact order in 02 registry is a proposed executable feature registry based on teammate's 12 physiological, 6 quality and 8 expert features per vital. ## Extraction proposal
At source time t use trailing 15s [t-15,t] with unique event timestamps and causal available observations; define boundary inclusion consistently (recommended (t-15,t], initial t=0 latest only). Latest eligible within configured freshness, median/min/max/sample SD (n>=2), 60s/300s OLS slope on actual source seconds (>=2 distinct eligible samples and coverage per clinical policy), previous eligible baseline, delta, robust z=(value-baseline)/robust spread with minimum spread agreed before training, abnormal duration from clinical expert, freshness seconds since last eligible sample. Missing or insufficient feature -> mask 0, normalized value 0; valid normalized zero -> mask 1. Use no future interpolation, no raw suspect/invalid values in physiological estimates; retain raw evidence separately. Quality flags describe latest raw measurement (present, valid, suspect, invalid); absent all zero, quality fractions over expected sample cadence, gaps count missing, undefined denominator explicitly mark frame ineligible or document neutral encoding. No unbounded NaN/Inf.

Expert features use component score 0–3, concern none/mild/moderate/high 0/1/2/3, signed baseline delta, slope per second, eligible abnormal duration, support proportion of eligible other domains (no eligible support -> unavailable), reliability low/moderate/high 0/1/2 and interpretation uncertainty low/moderate/high 0/1/2; unknown mask0. Map actual ExpertEvidenceV1 fields, don't recalculate independent clinical logic.

Context: binary features represent positively documented/confirmed states; 0 with mask1 only if explicitly known negative or valid mutually exclusive category; absence of documentation => mask0 except documented scope explicitly allows known absence. Condition history is not active diagnosis. Current beta blocker and adherence unknown unless verified; oxygen scale2 only authorized, oxygen targets not physical model constraints. Context age_at_discharge sourced from verified KB, days since discharge as-of source clock when known; do not derive from current replay wall time. Recovery phase only approved/context documented. Activity level only after actual agreed scale mapping; until then mask0. Symptoms use as-of reports; never future. Proposed slots are not evidence that records contain those values.

Temporal/baseline 16: per-vital established/frozen/available and calibration_fraction=min(eligible stable seconds/900,1), using existing baseline policy. Unknown state must use explicit availability/eligibility; document exact enum mapping. No elapsed simulation time/source type/scenario ID as learned features; keep metadata outside vector. No target or ground truth in encoder. Fit mean/std on available training rows only, store epsilon and clipping policy, no normalization on validation/test. Binary/mask/ordinal/fraction encoding fixed and versioned; normalize continuous values only, with zero-variance handling and recorded stats. Fit learned projection jointly only if selected; deterministic vector extraction independent of trainable network. Output exactly 264 finite values, registry hash, normalizer hash, key/frame/context refs and availability. Fail incompatible model/registry. Test missing, constant signal, irregular source-time, cross-key, no leakage, exact indices and offline/runtime parity.
