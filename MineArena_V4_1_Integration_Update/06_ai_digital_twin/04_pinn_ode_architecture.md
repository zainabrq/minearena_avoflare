# Hybrid PINN-ODE model design
V4.1 core: encoded manifest + context -> current state estimator and constrained parameter estimator -> mechanistic ODE + shared context-conditioned learned residual -> differentiable solver -> state reconciliation / trajectory decoder and uncertainty. PyTorch + torchdiffeq. Do not replace with SNN or a stand-alone LSTM. Architecture parameters below are proposed engineering defaults subject to AI approval, not validated model choices.

## Interfaces
EncoderFrameV1: 264 ordered values at 15s source boundaries, masks, registry/normalizer versions. Proposed history 20 frames (5min; define inclusion and require coverage), no future. State estimator returns 4 physiological estimates and uncertainty, anchors valid observations and never overwrites raw records. Parameter estimator returns constrained patient-conditioned p with versioned units and bounds from approved equation registry; unknown priors explicitly flagged. External u available at prediction cutoff only; future assumed held/unknown per versioned model assumption. Residual neural network maps x,z,u to four scaled derivative corrections; proposed small MLP (e.g. 2 hidden layers 64 units, smooth activation), final architecture and residual bound chosen by AI, document exact shapes. Context projection optional; jointly trained, not separate large encoder. Use normalization consistent with physical units before ODE evaluation; convert derivative back to physical units and check dimension consistency.

## Solver
Use differentiable torchdiffeq solver; initial choice adaptive dopri5 or fixed RK4, select on measured stability/latency and reproducibility; specify tolerances/step size in artifact, no invented performance. Integrate time in seconds, forecast at 15s points up to eligible horizon; primary 300s, secondary 900s, experimental 1800s. Detect nonfinite/out-of-bounds/unstable output, fail/abstain rather than silently clip; evaluate state constraints and parameter transforms. Train shared weights offline; freeze during runtime; adapt patient state/parameters only by approved estimator/reconciliation. Model job asynchronous outside P0; keyed immutable frame, timeout, version checks. Forecast experimental until held-out validation and explicit eligibility gate; no clinical validation claim. Model approval gates: equation registry, feature registry, train split, artifacts, numerical stability and measured evaluation. No fake outputs if missing.
