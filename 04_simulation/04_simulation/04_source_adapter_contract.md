# Shared source adapter contract | MATLAB + BIDMC

Authority: 05_backend/11_source_adapter_contract.md and final shared contracts. This document defines source-side mapping, not an alternative backend API. Claude/backend owns conversion, signing, retry and secure submission; MATLAB owner provides actual observed rows/callback. Do not send to legacy localhost:8000/observations raw endpoint by default.

## Runtime-safe input
| Canonical field | MATLAB integrated observed CSV | BIDMC numeric extract |
|---|---|---|
| source_namespace | synthea simulation namespace per approved mapping | bidmc |
| subject_id | patient_id P001–P010 | record (preserve leading zeros, e.g. BIDMC-13) |

| SpO2 % | SpO2 | spo2_pct |
| temperature Cel | TEMP | unavailable, not zero or generated by legacy replay |
| source | source | BIDMC |
| producer quality | only authentic available channel status, unknown if absent | unknown unless supported by source; preserve missing/raw zero |

The callback in run_minearena_realtime_replay receives all patient rows for a second. Split by authorized patient/session, create one native FHIR Observation per channel per tick or approved Bundle. Generate stable event identifiers per session/time/channel, sequence per registered device/session stream according to final contracts. Source time may be relative or historical. Set effectiveDateTime to actual measurement time if known, otherwise to a documented synthetic/replay epoch plus relative offset; never claim fabricated epoch is original clinical date. Separate request timestamp, receipt time, source seconds and measured time. Replay speed affects pacing only.

## FHIR transport
POST /api/v1/observations (proposed; verify implemented route). Content-Type application/fhir+json. Native Observation includes status, vital-signs category, subject reference, effectiveDateTime, code, quantity or dataAbsentReason (not both), device where registered, provenance as available. HR 8867-4 /min, RR 9279-1 /min, SpO2 2708-6 % (optional 59408-5 additional pulse-oximetry code), TEMP 8310-5 Cel. Preserve raw recorded zero as suspect/quality-evaluation candidate; never convert all zero values to missing. Null/NaN -> no valueQuantity, appropriate dataAbsentReason. Reject invalid types/units, not clinical abnormality. For absent BIDMC temperature, omit the channel or send explicitly absent per shared contract; never generate false reading.

HTTPS via NGINX. Device JWT + HMAC-SHA256 over exact request representation, transmission timestamp (configurable ±30s), nonce, sequence, idempotency key; use agreed backend canonicalization. Never sign offline truth. No keys in code, logs or CSV. Identical retry same event ID/body, fresh nonce/signature as agreed, return existing acceptance; altered body conflict. On 429/503 bounded backoff, track pending and do not falsely increment accepted count. HTTP 202 means durable accepted, not persisted/delivered. Record event/request IDs and later HAPI retrieval evidence. Do not return clinical score/priority to device by default.

## Allowed attachment metadata
Only explicit authorized simulation presentation events may set confirmed attached/removed UI state. Fault truth labels stay offline and do not influence clinical scores, quality classification or forecast. If no authorized event exists, dashboard shows suspected removal/unknown based on runtime evidence; do not infer removal from disconnect. Evaluate artifact detection blind to simulator labels. Separate evaluation/visual-control channel from clinical data and log provenance. Do not expose hidden future onset or intervention to runtime.

## Pacing and resilience
At 1x emit tick k at monotonic wall_start+(source_time-source_start); at 10x divide by 10. Do not block safety on collection windows. Keep bounded producer queue and per-session sequence order, log missed deadlines and actual acceptance, support cancellation/reset and isolated replay IDs. A no-packet connectivity test must omit transmissions while retaining expected sequence/gap metadata in offline labels. All-null samples test missing data separately. Backpressure cannot convert urgent clinical severity to routine.
